## Review Focus

Inputs the spec implies but does not spell out. Each has a test in the task named.

1. Tyre maths at the edges: standstill, reversing, handbrake at zero speed, off track in the wet. Every car state stays finite. Test in task 9.
2. A gamepad unplugged while the throttle is held, or a pad without the standard mapping. Inputs fall to zero and keys take over; a non standard pad is named on screen and ignored. Test in task 15.
3. Browser storage blocked, full or holding corrupt data (settings and ghost). The game boots, the ghost lives in memory, nothing throws. Tests in tasks 14 and 16.
4. A saved circuit id from v1, or an id that no longer exists. v1 ids map to their v2 circuit; anything else falls back to the default circuit with no crash. Test in task 14.
5. A malformed, truncated or wrong version trace handed to the replayer. It is rejected with a message that starts `bad trace:`. Test in task 7.

### Task 1: Legacy oracle and sim-2 reference digests

A script that runs today's physics, read from git at commit `7b58256`, through a transcription of today's race loop, and writes one digest per circuit. Tasks 2 to 7 must keep matching these digests. The oracle is deleted in task 8.

**Files:**

**Interfaces:**
- Produces, in `test/lib/sim.js`:
  - `STEP = 1 / 60`
  - `stateBytes(cars, raceTimeMs) -> Uint8Array`: a `Float64Array` holding, for each car in index order, `pos.x, pos.z, yaw, vFwd, vLat, yawRate, progress, finishTime, bestLap, lapsDone`, then `raceTimeMs` last; returned as the bytes of its buffer.
  - `sha256(bytes) -> string` (hex, node `crypto`).
  - `quantise(inp) -> inp`: `steer = Math.round(clamp(steer, -1, 1) * 127) / 127`, `throttle` and `brake` the same with 255 and range 0 to 1. Copied from G:1023 to 1025.
  - `makeReporter() -> { assert(cond, name, detail), ok(name), skip(name, why), done() }`; `done()` prints totals and exits 1 on any failure. Same output shape as `test/physics.test.js`.
  - `throws(fn, part) -> boolean`: true when `fn` throws an `Error` whose message contains `part`.
- Produces: `test/golden/sim-2.json` as `{ "source": "7b58256", "races": { "<v1 id>": { "ticks": <int>, "sha256": "<hex>" } } }` for the three v1 ids.
